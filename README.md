# iPAS 色彩規劃管理師（初級）練習站

文化大學資訊傳播學系 朱尚禮老師｜115 年考前練習用

- 練習站：開啟 GitHub Pages 後的網址（`https://hitaiwan0705.github.io/ipas-cpm-practice/`）
- 60 色票卡：`card.html`（教師版加 `#specs` 顯示孟塞爾標記）

## 練習模式

| 模式 | 用途 |
|---|---|
| 診斷卷 | 第一次做固定 20 題；之後變成「平行診斷卷」，同領域、同難度換題 |
| 組卷練習 | 依科目自動組卷，難度約易 4：中 4：難 2，優先出沒做過的題，計算題每次換數字 |
| 錯題重練 | 答錯的題目換成同一內容代碼的平行題 |
| 自由選題 | 依科目、難度、領域篩選後自選 |

難度定義：**易**＝單一主題；**中**＝複合主題；**難**＝複合主題的情境應用。

實作題以 60 色票卡的**票號**作答。色票由孟塞爾標記或 CIELAB 值換算為 sRGB，顯示在 L*≈50 中灰背景上；螢幕未經校正時只是近似色。之後會對應實體色票 CPG-49a。

## 設定 Google Sheet 回傳（老師做一次）

1. 開啟回傳用的 Google Sheet → 「擴充功能」→「Apps Script」。
2. 把 `apps-script/Code.gs` 的內容全部貼上，儲存。
3. 上方函式選單選 `setup` → 執行，依畫面完成授權（會出現「Google 尚未驗證這個應用程式」，點「進階」→ 前往）。
4. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→ 部署，複製網址。
5. 把網址貼到 `config.js` 的 `endpoint`，推上 GitHub。

Sheet 會有：`場次`、`作答紀錄`（每題一列），以及自動更新的分析表 `學生×領域`、`學生×難度`、`內容代碼弱點`、`題目分析`。

## 檔案

- `bank.js`：題庫、色票卡、診斷卷題號（由 build 腳本產生）
- `data/題庫.csv`：同一份題庫的表格版，方便審題與修改
- `app.js`：組卷、作答、計分、回傳；含 8 種隨機數字計算題模板
- `apps-script/Code.gs`：Google Sheet 收集程式
